# ManiSkill StackCube 任务最终报告

## 1. 项目结论

StackCube 第二阶段任务已完成。本项目在 ManiSkill v3.0.1 原生
`StackCube-v1` 环境中，完成了从自定义课程探索、官方 PPO-fast 基线训练、
全 checkpoint 筛选，到最佳 checkpoint 低学习率续训的完整迭代。

最终模型在与上一代模型完全相同的 1,000 环境、固定向量种子
`20260722` 的严格评估中达到 **894/1,000（89.4%）**，较上一代最佳模型的
821/1,000（82.1%）提升 **7.3 个百分点**。在额外的 seed 0、1,000 环境
评估中达到 **920/1,000（92.0%）**。

严格成功要求方块 A 被正确堆叠到方块 B 上、机械臂完成释放，并且方块最终
保持静止。结果不是仅依据奖励或肉眼判断，而是使用 ManiSkill 原生成功判定
和固定种子批量评估得到。

## 4. 实验迭代过程

### 4.1 自定义课程实验 SC-S1 至 SC-S5

项目首先进行了五轮自定义课程实验，依次尝试原生小规模 PPO、运输奖励塑形、
局部运输课程、到位自动释放和静止后释放。实验确认了以下问题：

1. 小规模训练几乎总能学会抓取，但难以稳定运输和精确放置。
2. 单纯增加运输 shaping 不能解决最终堆叠判定。
3. 缩短运输距离能提高接近目标的概率，但释放仍不稳定。
4. 强制自动释放只能产生少量训练成功，确定性策略仍不可靠。
5. 静止门控进一步增加了稀疏性，效果下降。

这些实验均作为有效的失败消融保留，没有删除其配置、日志或 checkpoint。

### 4.2 官方 50M PPO-fast 基线 SC-O1

随后采用 ManiSkill 官方 StackCube 配置：

- 4,096 个并行环境
- rollout 长度 16
- 8 个 PPO update epochs
- 32 个 minibatches
- 学习率 3e-4
- gamma 0.8
- GAE lambda 0.9
- 50,000,000 环境步

训练约 29.5 分钟，共保留 31 个周期 checkpoint 和最终 checkpoint。对全部
32 个权重进行固定 100 环境筛选后，`ckpt_726.pt` 在两组独立种子上分别取得
80/100 和 84/100，累计 164/200，为该轮最稳定的模型。

该模型在固定种子 `20260722` 的 1,000 环境正式评估中取得 821/1,000
（82.1%），成为续训前基线。

### 4.3 低学习率续训 SC-O2

从保留的 `ckpt_726.pt` 权重启动完全独立的续训 run。旧 run、旧模型、配置、
日志和评估结果均未被修改。

续训参数：

- 新增环境步：10,000,000
- 初始学习率：1e-4，线性退火至 0
- 并行环境：4,096
- rollout：16
- update epochs：8
- minibatches：32
- gamma：0.8
- GAE lambda：0.9
- GPU：物理 GPU 1
- 训练时间：约 7 分 51 秒

该轮保存了 7 个周期 checkpoint、`final_ckpt.pt`、源 checkpoint 副本、完整
启动命令和训练日志。

### 5.3 失败分类

最终模型在 matched-seed 正式评估中共有 106 次失败：

- 未抓住：2
- 抓住但从未精确到位：93
- 到位但从未释放：3
- 已释放但未静止：8
- 其他时序问题：0

相比上一代的 179 次失败，新模型将总失败数减少 73 次，降幅约 40.8%。释放
和稳定性问题已明显缓解，当前主要剩余瓶颈集中在最终精确放置。

本项目采用两组独立 100 环境筛选、同种子 1,000 环境正式对比，以及额外
seed 0 的 1,000 环境复验，避免以单次小样本或在线 16 环境指标选择模型。
